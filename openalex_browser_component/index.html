Browser-local OpenAlex credentials. Choose a local JSON file containing api_key and email. This component reads the file in your browser; it sends the key only to OpenAlex in an HTTPS authorization header. The email is not sent. The file and credentials are not uploaded to Streamlit or saved by this component.

The app host supplies this code and could change it; browser extensions may also have access. Use a host and browser you trust. The Streamlit server does receive the search results and non-secret search settings. OpenAlex receives your search query.

On your computer, create a plain-text file named openalex_credentials.json containing {"api_key":"YOUR_KEY", "email":"YOUR_VERIFIED_EMAIL"}. Replace both placeholders, save it privately, and never commit or share it.

Choose a file, then select Run Search. No search starts automatically.
